# 2.º Ano

Unidades curriculares do segundo ano da Licenciatura em Engenharia Informática no ISEC (Instituto Superior de Engenharia de Coimbra).

## 1.º Semestre

- Bases de Dados
- Introdução à Inteligência Artificial
- Introdução às Redes de Comunicação
- Investigação Operacional
- Programação Orientada a Objetos
- Sistemas Operativos

## 2.º Semestre

- Cablagem Estruturada
- Encaminhamento de Dados
- Gestão
- Segurança
- Serviços de Rede I
- Sistemas Operativos II
