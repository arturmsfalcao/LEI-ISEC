# 1.º Ano

Unidades curriculares do primeiro ano da Licenciatura em Engenharia Informática no ISEC (Instituto Superior de Engenharia de Coimbra).

## 1.º Semestre

- Álgebra Linear
- Análise Matemática I
- Eletrónica
- Introdução à Programação
- Sistemas Digitais
- Tecnologias Web

## 2.º Semestre

- Análise Matemática II
- Fundamentos de Computação Gráfica
- Linguagens Script
- Métodos Estatísticos
- Programação
- Tecnologias e Arquiteturas de Computadores
